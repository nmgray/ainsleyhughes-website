# GENESIS PROMPT: AI-Optimized Real Estate Site & Lead Capture Engine

Copy and paste the following prompt into an advanced AI development agent or code generator to build, duplicate, or structure the website.

---

### Role & Objective

You are an expert full-stack web developer and Generative Engine Optimization (GEO) architect. Your goal is to build/duplicate a high-performance, AI-forward real estate website optimized to be discovered, cited, and recommended by conversational search engines (like ChatGPT, Gemini, and Perplexity) while aggressively capturing seller leads and integrating with CRM/automation platforms (such as ChatGPT custom actions and KW Command/Zapier webhooks).

---

### Key System Specifications & Architecture

#### 1. Technical Framework & AI Readability (GEO)

- **Structured Data (JSON-LD):** Implement robust, nested schema markup across all pages (`LocalBusiness`, `RealEstateAgent`, `Service`, `FAQPage`, and `Review`). Ensure `sameAs` properties link directly to social profiles (Instagram, Facebook, LinkedIn) and official directory listings.
- **Semantic HTML & Clean DOM:** Use explicit heading hierarchies (`H1`, `H2`, `H3`) structured around natural language Q&A queries that target local real estate intent (e.g., _"How to price a home in [Location]"_, _"What are closing costs for sellers in [Location]"_).
- **Machine-Readable Content Blocks:** Provide dedicated FAQ sections and concise summary blocks designed for LLM extraction and zero-click search snippets.
- **Automated Sitemaps & Metadata:** Maintain dynamic XML sitemaps and AI-assisted metadata generation for all property listings, neighborhood guides, and market reports.

#### 2. Seller Lead Generation Engine

- **High-Value Lead Magnets:**
  - _Instant Home Valuation / Comparative Market Analysis (CMA) Calculator:_ Interactive multi-step form collecting property details in exchange for an instant automated valuation report.
  - _Hyper-Local Seller Guides & Market Trend Reports:_ Gated PDF/digital guides providing local inventory data, days-on-market stats, and staging checklists.
- **Interactive Conversion Paths:**
  - Integrated scheduling widgets (e.g., Calendly/SavvyCal) for listing consultations embedded directly within high-intent landing pages.
  - Intelligent conversational capture widget/chatbot trained on local real estate FAQs to pre-qualify sellers and gather contact info 24/7.
- **Traffic Tracking & Attribution:** Append UTM tracking parameters dynamically across all inbound social/AI channels to monitor lead origin and conversion efficiency.

#### 3. Integrations & Tooling Connectors

- **ChatGPT Custom Actions / GPTs:** Expose an OpenAPI-compliant endpoint (`/api/llm-tools`) allowing custom GPTs to fetch up-to-date neighborhood market data, schedule consultations, or query valuation logic directly.
- **CRM Webhooks (KW Command / Zapier):** Implement secure webhook endpoints (`POST /api/leads`) that instantly push captured seller lead data (name, property address, contact info, valuation metrics, UTM source) directly into KW Command or Zapier automation pipelines.
- **Social Media Synergy:** Embed Open Graph meta tags (`og:title`, `og:description`, `og:image`) optimized for Instagram, Facebook, and LinkedIn sharing, ensuring visual cards load cleanly when shared.

---

### Implementation Instructions for the AI Builder

1. **Scaffold the Project:** Initialize a high-speed, SEO-friendly framework (Next.js/React or similar modern stack optimized for server-side rendering and fast Core Web Vitals).
2. **Implement Schema & Meta Layer:** Build reusable components for dynamic JSON-LD injection and Open Graph tags.
3. **Build Seller Funnels:** Create the multi-step valuation calculator, gated resource download forms, and consultation booking components.
4. **Configure API Endpoints & Webhooks:** Write backend route handlers to securely transmit lead payloads to external CRMs (KW Command/Zapier) and serve structured data endpoints for AI consumption.
5. **Output Clean, Modular Code:** Provide complete code snippets, configuration templates, and setup instructions for deployment.
